# 一方小海 · Tiny Tides

直接打开 `dist/index.html` 即可运行，脚本与自然录音均已内嵌，不依赖 CDN。需要支持 WebGL 2 的现代浏览器。

- 拖动旋转，滚轮／双指缩放；右上角可恢复初始视角。
- 「海浪大小」可实时调整0%–200%；0%接近静水，默认100%的波幅约为上一版的2.2倍。调整平滑生效，切换天气后保留当前设置，重新打开恢复100%。船只、尾流、雨滴涟漪与海豚同步跟随水面。
- 左上角显示本地时间。每段天气约60秒，依次为晴天 → 小雨 → 暴雨 → 黄昏 → 夜景，循环播放。
- 手动点击天气会重置本段天气计时，船只、尾流和镜头保持连续。切到后台暂停航行计时。
- 晴天在8–18秒后有四只海豚错落经过，跃出水面并在边缘潜下。每只约10秒，入场间隔1.1秒。海豚有弧形背线、长吻、眼睛、白腹、弯曲背鳍及水平双叶尾，切换天气时缓慢潜下。
- 小雨细密轻柔，有25%机会出现一次远雷；暴雨浪高约为晴天1.35倍，仍保持低幅柔波，约16–31秒间隔出现短暂闪电。
- 黄昏采用低角度金色阳光和暖色船灯；夜晚为深色背景、模型上空的38颗微光与小月亮。每次打开页面的首次夜景必定出现极光：约3.5秒开始，四层立体光幕逐层展开，约18秒完成；后续夜景有45%机会在22–34秒后出现。重选当前夜景保留首次必现标记。
- 极光采用缓慢弯曲的半透明光幕，青绿、青蓝与局部紫粉自然渐变，内部有柔和褶皱和移动亮芯。所有光幕固定在模型上空，边缘自然淡出；海面同步泛起模糊流光，船体和海洋切面受到微弱彩色照明。离开夜景时整体平滑淡出。
- 「听海」开启真实海浪、雨、海鸥与远雷录音，默认音量22%，可调音量。夜晚更加安静，海鸥仅在晴天／黄昏间歇鸣叫。默认静音；页面隐藏时声音淡出暂停，返回后恢复。

海面采用无镜面反射的漫反射材质，低幅慢速长波配连续柔和明暗，去掉颗粒纹理；白色轮船、尾流和雨滴涟漪都跟随同一水面高度。海鸥是简洁多边形身体和翼面；晴天四只、小雨和黄昏两只，暴雨与夜景全部隐藏，回晴时淡入。场景不再显示云朵。晴天恢复浅色背景，夜间使用近黑背景。

## 音频许可

录音来自 Wikimedia Commons，完整来源、作者、许可和处理方式见 [SOUND_CREDITS.md](SOUND_CREDITS.md)，页面内「声音来源」也可查看。网络录音已嵌入独立 HTML，播放无需外网或麦克风权限。

## 修改与构建

`npm ci` 安装依赖，`npm test` 运行16项行为测试，`npm run build` 生成独立 HTML。

- main.js：场景、天气过渡、船体与波浪渲染。
- motion.mjs：航线、波浪、天气循环、随机事件和海豚路径。
- scene-effects.mjs：海豚、星空和闪电。
- aurora.mjs：四层立体极光、演出时间线、共享海面染色和局部照明。
- ambient-audio.mjs / audio-mix.mjs / audio/：实地录音调度、混音与素材。
- template.html：响应式界面、时间和音量控件、来源署名。
- build.mjs：打包内嵌脚本和音频。

Three.js 固定为0.180.0，许可见 THREE-LICENSE.txt。浏览器检查覆盖桌面与390×844窄屏、五种天气、自然录音解码与声音开关；纯逻辑测试覆盖完整天气周期、海豚边界、随机事件分支、录音静音／隐藏后的恢复。硬件扬声器听感和实体手机手势未实测。
