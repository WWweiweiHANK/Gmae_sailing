# 一方小海 · Tiny Tides

打开 `dist/index.html` 即可运行，无需服务器或联网下载依赖。使用支持 WebGL 2 的现代浏览器。

- 鼠标左键拖动 / 单指拖动：旋转视角。
- 滚轮 / 双指手势：缩放。
- 右上角按钮：恢复初始视角。
- 底部按钮：平滑切换晴天、雨天、夜景，船只航行不中断。
- 右上角「听海」：开启／关闭轻柔环境音。晴天为海浪与间歇海鸥鸣叫，雨天增加雨声，夜晚降低音量与鸣叫频率。切到后台会淡出并暂停音频，返回时恢复；浏览器中断音频时可再次点击开启。

包含分层海洋截面、米白底座、连续长波与细涟漪、克制的浪尖泡沫、胶片感青蓝海色、绿色背景、循环航线、随浪起伏的船与尾流、四只双弧翼海鸥、局部降雨与涟漪、月亮星光和夜间船灯。

环境音使用 Web Audio 本地合成，不需要外部音频文件、联网或麦克风权限。默认静音，点击「听海」开始。

## 修改与构建

`npm ci` 安装构建依赖；`npm run build` 生成独立 HTML；`npm test` 检查航线及天气状态连续性。

`main.js` 为场景，`motion.mjs` 为航线、波浪和天气状态，`ambient-audio.mjs` 为环境音，`template.html` 为界面，`build.mjs` 打包内联脚本。Three.js 固定为 0.180.0，完整许可随附于 `THREE-LICENSE.txt`。

已验证桌面、窄竖屏、390×844 手机布局；天气按钮、鼠标旋转缩放、恢复视角及 WebMCP 天气入口。浏览器无渲染错误。触摸手势由 OrbitControls 提供，未在实体手机上测试。
